# Manual Publishing Checklist

**Status:** `DRAFT ONLY` — **EXTERNAL PUBLISHING REQUIRES ANTON APPROVAL**

Run this checklist **before every external publish** on LinkedIn, Facebook, Instagram, or YouTube. Copy source: [09-LAUNCH-POSTS.md](./09-LAUNCH-POSTS.md).

---

## Pre-publish (Anton — mandatory)

- [ ] **A1** — Atom ID recorded (e.g. L-01, O-02, D-01)
- [ ] **A2** — Anton has read the full atom in [09-LAUNCH-POSTS.md](./09-LAUNCH-POSTS.md)
- [ ] **A3** — Anton explicitly approves this publish (verbal or written OK)
- [ ] **A4** — Platform target confirmed (LI / FB / IG / YT)
- [ ] **A5** — Scheduled date matches [08-FIRST-30-DAYS-CONTENT.md](./08-FIRST-30-DAYS-CONTENT.md) (or intentional deviation noted)

---

## Copy compliance

- [ ] **C1** — No bank account numbers anywhere in post, caption, or image
- [ ] **C2** — No revenue or lead-volume guarantees
- [ ] **C3** — No client names without written consent
- [ ] **C4** — No ERPNext internal URLs, admin URLs, or secrets
- [ ] **C5** — Starting prices match canonical offers (MUR 35,000 / 45,000 / 45,000)
- [ ] **C6** — Three offers only — no Automation Starter or unlisted services
- [ ] **C7** — Deposit language present where commercial terms mentioned (50%, cleared funds)
- [ ] **C8** — Primary CTA is buyer-action oriented ("Book a discovery call"), not internal process jargon
- [ ] **C9** — Instagram caption includes "link in bio" (no fake clickable links in caption)

---

## Link and contact

- [ ] **L1** — Discovery CTA points to `https://corpflowai.com/contact#discovery` (or approved UTM variant per [07-CONTACT-AND-LINK-MAP.md](./07-CONTACT-AND-LINK-MAP.md))
- [ ] **L2** — Offer posts include correct `/offers/*` path
- [ ] **L3** — Email references use `support@corpflowai.com` only
- [ ] **L4** — Instagram bio link still points to discovery URL
- [ ] **L5** — YouTube description includes discovery link + pinned comment prepared

---

## Visual assets

- [ ] **V1** — Image/video dimensions match platform spec ([12-ASSET-INVENTORY.md](./12-ASSET-INVENTORY.md))
- [ ] **V2** — No placeholder watermarks or draft overlays on public publish
- [ ] **V3** — CorpFlowAI branding consistent (logo, colours per visual standard)
- [ ] **V4** — Text readable on mobile (test on phone before publish)
- [ ] **V5** — Video has captions or on-screen text for silent viewing (IG Reels, YT Shorts)

## Platform-specific

### LinkedIn

- [ ] **LI1** — Post type correct (text / image / video / document)
- [ ] **LI2** — First comment prepared with discovery link if needed
- [ ] **LI3** — Company page selected (not personal profile, unless founder post F-01)

### Facebook

- [ ] **FB1** — CTA button set to discovery URL where available
- [ ] **FB2** — No WhatsApp Business API auto-reply enabled
- [ ] **FB3** — Page (not personal profile) for business posts

### Instagram

- [ ] **IG1** — Format correct (feed / Reel / Story / carousel)
- [ ] **IG2** — Alt text added for feed posts (accessibility)
- [ ] **IG3** — Hashtags limited and relevant (max ~5–8, no spam tags)
- [ ] **IG4** — Story highlights updated if process/founder content

### YouTube

- [ ] **YT1** — Title, description, tags per [04-YOUTUBE-CHANNEL.md](./04-YOUTUBE-CHANNEL.md)
- [ ] **YT2** — Thumbnail uploaded (not auto-generated if possible)
- [ ] **YT3** — End screen / cards point to discovery (when available)
- [ ] **YT4** — Playlist assigned (Launch / Offers / Process / FAQ)

## Meta / policy holds (do not violate)

- [ ] **H1** — No paid Meta Ads created or boosted without separate Anton approval

- [ ] **H4** — No bulk outreach (email, WhatsApp, SMS)
- [ ] **H5** — Organic presence only — no ad account linking in this launch phase
