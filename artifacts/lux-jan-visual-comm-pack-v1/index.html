This is the Rare & Exclusive operating model. Not three products — three layers of the same CorpFlowAI application, branded for Lux.

Public Website

Admin / Application Layer

B · Business flow

From first enquiry to viewing.

One path. Each step has a clear owner and a next action — the same journey already proven in pieces on the Lux test desk.

01

New Enquiry

Website or concierge form. Email + telephone. Captured once.

02

Client Review / Active

Qualify. Shortlist. Move from new → contacted → qualified.

03

Next Action

Who calls, what is due, when — so nothing sits still.

04

Private Draft / Invitation

Confidential presentation or viewing invitation — prepared, manual send.

05

Viewing / Deal Progress

Invitation-only viewing, then clear deal progress forward.
