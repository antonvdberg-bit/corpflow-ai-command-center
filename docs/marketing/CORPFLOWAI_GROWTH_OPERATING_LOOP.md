## 1. Purpose and scope

**In scope:**

- Daily and weekly **awareness** discipline for a one-operator business.
- **Warm manual outreach** as the default first channel for Lead Rescue.
- Message quality, list quality, hooks, proof discipline, and leading indicators.
- A bounded **10-day awareness sprint** (§15) before scaling channels.

**Out of scope (this doc does not authorise):**

- Paid ads, cold scraping at scale, bulk email, n8n outbound, new CRM, new database.
- Public page copy changes, runtime features, payment automation.
- Testimonials, logos, or metrics not backed by real pilot evidence + permission.

**Success definition (first phase):** one **paying** USD 150 Lead Rescue pilot delivered with honest evidence — not follower count, not impressions.

## 2. First-channel decision — warm manual outreach is default

**Obscurity is the first enemy.** Before optimising conversion details, Anton must spend focused time where buyers already know him.

| Channel | CorpFlowAI default | Why |
| ------- | ------------------ | --- |
| **Warm manual outreach** | **YES — start here** | Mauritius network, referrals, prior conversations; no ad spend; matches first paid-pilot pack |
| Cold outreach | Hold until warm path proves one pilot OR Anton approves cold packet | Higher friction; list quality risk |
| Content (posts, video, articles) | Support only in sprint — not primary channel yet | Slow proof; use as *give* not main *ask* |
| Paid ads | **NO** until Spend gate (§13) | No budget proof threshold met |

**Rule:** pick **one** Core Four channel as primary for the sprint. Default = **warm manual outreach**. Other channels are secondary until Anton flips the Channel gate.

## 3. Weekly operator growth loop

Repeat every week until first paid pilot is **delivered** (operator pack §15 E1–E8).

| Day block | Activity | Time (realistic) |
| --------- | -------- | ---------------- |
| **Mon — Plan** | Review leading indicators (§12); pick 3–5 warm names; score with outreach worksheet | 30–45 min |
| **Tue–Thu — Awareness** | One focused block/day: manual messages, follow-ups, discovery calls | 45–60 min/day |
| **Wed — Hook review** | Rewrite one hook using hook bank (§8); archive winner/loser | 15 min |
| **Fri — Give** | One give-first action: helpful comment, intro, short tip — no hard ask | 20 min |
| **Fri — Log** | Update private spreadsheet + one line in `artifacts/chat_history.md` | 10 min |
| **Sat/Sun — Off** | Optional reply-only; no new doctrine | — |

**Weekly outputs (minimum):**

- ≥3 manual touchpoints (new or follow-up) to **warm** prospects.
- ≥1 qualification conversation or clear no-go logged.
- Leading indicators sheet updated (§12).
- Zero fabricated proof; zero automated sends.

## 4. Four-hour awareness block (Anton-realistic)

Full-time founders may run four hours/day on acquisition. Anton runs a **bounded business** — use this **compressed** version:

| Block | Duration | What to do |
| ----- | -------- | ---------- |
| **A — List** | 20 min | Score 1–3 warm prospects (`FIRST_OUTREACH_CANDIDATE_WORKSHEET.md`) |
| **B — Outreach** | 30 min | Draft + send **one** personal message (email / WhatsApp / LinkedIn) |
| **C — Follow-up** | 20 min | Same-day replies; nudge warm thread; log status |
| **D — Give** | 15 min | Share something useful (intro, answer, resource) with **no** invoice ask |
| **E — Proof capture** | 10 min | Note objections, buyer words, process gaps — private only |
| **F — Hook** | 10 min | One hook variant in hook bank (§8) |

**Total:** ~105 minutes on heavy days; **≥45 minutes minimum** on light days.

**More beats new:** repeat blocks B–C daily before opening a new channel or tool.

## 6. Clear-not-clever writing checklist

Target **third- to fifth-grade** reading level in outreach and drafts. Clarity beats cleverness (`BRAND_AND_CONVERSION_DOCTRINE.md`).

Before sending any manual message:

| # | Check | Pass? |
| - | ----- | ----- |
| C1 | One idea per message | |
| C2 | Short sentences; no jargon (CRM, funnel, AI agent, leverage) | |
| C3 | Concrete pain words buyer uses (*"messages get buried"*) not CorpFlow internals | |
| C4 | One CTA only (call **or** intake link — not both) | |
| C5 | No guaranteed revenue, lead volume, or "AI replies for you" | |
| C6 | Sounds like Anton talking to one person — not a newsletter | |
| C7 | Read aloud in 20 seconds or less | |

**Fail any check → rewrite** using operator pack §3 templates or warm action pack — do not invent clever angles.

## 7. Proof-over-promise rules

State facts; show only what CorpFlow can evidence (`PROOF_VALIDATION_ASSET_PLAN_LR_V1.md`).

### 7.1 Pre-proof (today — no paying pilot published)

| May say | May not say |
| ------- | ----------- |
| USD 150 launch pilot, 48h setup, 7-day monitoring | "Trusted by…", client logos, star counts |
| Manual invoice after intake review | "% more leads", revenue saved |
| We do not guarantee new revenue | Named client case unless real + permitted |
| Launch pilot / first clients window | Fake testimonial or metric |

### 7.2 First proof (one pilot delivered, permission pending)

| May say (private / call) | May not say (public) |
| ------------------------ | -------------------- |
| Process worked / gaps noted honestly | Client name on website without G7 |
| Counts from day-7 recap (buyer-shared) | Fabricated before/after revenue |
| "We are capturing permission for a case" | Generic "our clients see…" |

### 7.3 Repeat proof (2–4 pilots, permissions on file)

| May say | Gate |
| ------- | ---- |
| Named or anonymised testimonial with permission | Client gate (§13) |
| One quantified case if buyer approved the number | Proof gate + written line |
| Scale cold or content **slightly** | Volume gate — still manual sends |

**Promise rule:** sell the **movement** from lost enquiries to visible follow-up discipline — not AI magic or guaranteed outcomes.

## 8. Hook bank format (proof / promise / plan)

Maintain a **private** hook bank (sheet or notes — not repo PII). Each hook has three lines:

| Field | Question it answers | Lead Rescue example (structural — customise per prospect) |
| ----- | ------------------- | --------------------------------------------------------- |
| **Proof** | Why believe you? | "I help owner-operators who lose WhatsApp enquiries — manually, with a 7-day pilot." |
| **Promise** | What changes for them? | "You see every enquiry in one place and get a daily summary — no new ads." |
| **Plan** | What is the next step? | "15-minute call; if it fits, you submit intake and I send a USD 150 pro-forma." |

**Hook quality gate:**

| Score | Rule |
| ----- | ---- |
| 0 missing | All three fields present |
| Specific | Names **one** pain (lost/delayed enquiries) not "grow your business" |
| Honest | Proof field uses only true facts (location, operator-led, pilot terms) |

**Daily hook review (10 min):** write one variant; mark **use / retire / test**; 70% of sends should reuse a **use** hook (§9).

---

## 9. 70 / 20 / 10 message reuse rule

Avoid shiny-object syndrome — **steal from yourself**.

| Share | Meaning | Lead Rescue application |
| ----- | ------- | ----------------------- |
| **70%** | Repeat proven hooks/messages that got replies or calls | Same warm email/DM skeleton; swap name + one pain detail |
| **20%** | Adjacent variant (new niche angle, shorter subject, different channel) | Property vs contractor opening line |
| **10%** | New test (only after 70% lane has ≥5 sends logged) | New CTA framing — still one CTA |

**Do not** write ten new templates before sending ten messages.

---

## 10. Give / ask ratio

Maintain roughly **3.5:1** or **70:30** give-to-ask across a rolling week.

| Give (no invoice / no intake link) | Ask (intake, call, pro-forma) |
| ---------------------------------- | ----------------------------- |
| Intro two people who should meet | "Submit intake when ready" |
| Answer a business question publicly | Discovery call invite |
| Share a checklist or tip | Pro-forma after qualification |
| Congratulate / show up for someone | Follow-up after silence |

**Sprint rule:** on days you **ask**, ensure the prior two touchpoints were **give** or nurture — especially for warm network.

## 13. Decision gates

### 13.1 Channel gate

| Switch to | Requires |
| --------- | -------- |
| Cold outreach at scale | Warm path attempted; Anton approves cold pack cadence |
| Content as primary | Proof gate: at least one deliverable pilot OR explicit Anton decision |
| Paid ads | Spend gate below |

### 13.2 Proof gate

| Stage | Public marketing | Outreach |
| ----- | ---------------- | -------- |
| Pre-proof | Structural numbers only | No client names as social proof |
| First proof | Permission draft only | Paraphrase pain — no publish |
| Public proof | G7 + proof plan packet | Named quote/logo only after written yes |

### 13.3 Message gate

If clear-not-clever checklist (§6) fails → **rewrite** before send.

### 13.4 Hook gate

If proof / promise / plan any missing → **do not send**.

### 13.5 Volume gate

If leading indicators show **&lt;3 sends/week** for two weeks → **more** of same channel — not a new channel.

### 13.6 List gate

If replies are polite brush-offs → fix list (§11), not hook cleverness.

### 13.7 Ask gate

If two asks in a row with no give → pause ask; deliver give (§10).

### 13.8 Spend gate (ads)

Paid ads require **all**:

- Anton explicit budget line
- One delivered pilot or Anton-written exception
- Landing page unchanged and live-verified
- No guaranteed-results copy

Default: **closed**.

### 13.9 Client gate

No client-facing proof (site, social, deck) without **written** client approval.

### 13.10 Scale gate

Do not hire, automate sends, or build CRM until **manual loop** produces ≥1 paid pilot + operator review.

## 15. Lead Rescue 10-day awareness sprint

**Goal:** build **awareness and conversations** toward the first USD 150 pilot — warm-first, manual-only.

**Ground rules:**

- Anton sends every message personally.
- **No paid ads** unless Anton explicitly approves mid-sprint (unlikely).
- **No automated outbound.**
- Live CTA path: `https://corpflowai.com/lead-rescue` after qualification.
- Private tracking: outreach worksheet + spreadsheet copy — not repo PII.

### Day 1 — Select warm prospects

- [ ] Score 3–5 warm names (`FIRST_OUTREACH_CANDIDATE_WORKSHEET.md`)
- [ ] Pick **priority 1** only for first send
- [ ] Log leading indicators baseline (§12)

### Day 2 — First warm outreach (give-leaning)

- [ ] Send **one** short message (operator pack §3) — ask for conversation, not payment
- [ ] One give action (intro or helpful reply elsewhere)
- [ ] Hook bank: enter first proof/promise/plan set (§8)

### Day 3 — Follow-up + hook review **(review gate)**

- [ ] Follow up priority 1 if no reply (one nudge only)
- [ ] Draft message for priority 2 — **do not send yet** unless Day 2 got a yes
- [ ] **Review gate:** leading indicators — if 0 sends, fix today before new tactics
- [ ] Clear-not-clever pass on all drafts (§6)

### Day 4 — Awareness block

- [ ] 45-min block §4: list + one outreach + follow-up
- [ ] Log objections/themes privately

### Day 5 — Give-first day

- [ ] Two give actions (§10); max one soft ask
- [ ] 70% reuse: resend pattern from hook bank if new prospect ready

### Day 6 — Discovery prep

- [ ] If reply: book 15-min call (`AI_LEAD_RESCUE_DISCOVERY_CALL_SCRIPT.md`)
- [ ] If no reply: warm nurture only — no cold list building required this sprint

### Day 7 — Mid-sprint review **(review gate)**

- [ ] Count: sent, replies, calls, qualified, no-gos
- [ ] Proof-over-promise audit on all drafts sent (§7)
- [ ] Decision: continue warm only **or** ask Anton to authorise cold (Channel gate)

### Day 8 — Proof capture discipline

- [ ] Note buyer-language phrases (private) for future hooks — no publish
- [ ] Fulfilment checklist skim if call happened (`FIRST_PAID_PILOT_FULFILMENT_EVIDENCE_CHECKLIST.md`)

### Day 9 — Second warm touch or intake path

- [ ] If qualified: buyer submits intake; operator pack §5 path
- [ ] If not yet: one more warm name from shortlist — manual send

### Day 10 — Sprint close **(review gate)**

- [ ] Update all leading indicators (§12)
- [ ] Write one line in `artifacts/chat_history.md` (counts only — no PII)
- [ ] **Outcomes:** paid pilot in progress / qualified pipeline / honest no-go list
- [ ] Next: repeat weekly loop (§3) — do not add ads or automation

**Realistic outreach count:** **3–7 manual messages** total over 10 days (quality &gt; volume). Not 25 cold sends — that is a separate authorised packet after warm proof.
