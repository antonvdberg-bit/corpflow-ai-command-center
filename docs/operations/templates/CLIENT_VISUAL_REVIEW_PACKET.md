# Client visual review packet (default)

**Use for every client-facing preview before owner review.**  
A preview is **not** client-ready merely because it functions. Visual-first is mandatory.

## Packet contents (required)

1. **Preview URL** — anonymous-openable (Production or protection bypass). Not a Vercel-login wall.
2. **Screenshots** — 2–4 images:
   - Desktop homepage (full hero / first viewport)
   - Mobile homepage (first viewport + key CTA)
   - Optional: menu or key journey page
3. **One-page before / after summary** — what changed, why it is better (15-second grasp).
4. **Max 5 owner-review questions**.

## Client-review gate

Do **not** say READY FOR OWNER REVIEW unless:

- the page looks visually convincing (imagery + appetite / brand atmosphere);
- screenshots exist in the packet;
- a human can grasp the improvement in under 15 seconds.

## Non-goals

- Do not substitute long operator docs for this packet.
- Do not invent prices, addresses, or claims.
- Do not touch production DNS / chatbot logic / WhatsApp automation unless separately authorised.
