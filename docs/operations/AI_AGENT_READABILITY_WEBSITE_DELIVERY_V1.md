# Website delivery — optional agent-readable public knowledge (OKF)\n\nScope: bounded, public-only agent-friendly Markdown for CorpFlowAI's apex public marketing site. This is an interoperability supplement; robots.txt, sitemap.xml, canonical HTML and authoritative commercial copy remain primary. Google Search does not use OKF or llms.txt for rankings.\n\nImplementation: host-isolated Next.js routes /okf/index.md, /okf/{slug}.md and /llms.txt, backed by a hand-curated public-page allowlist in lib/public/agent-readable-knowledge.js. No tenant data, DB calls, private/internal content, unpublished offers or secrets. Do not add arbitrary sitemap pages automatically; each added page must be content-reviewed.\n\nReusable client delivery check (opt-in only, separately approved per site): confirm canonical public pages; sitemap/robots/structured-data correctness; approved publicly visible claims; only then add agent-readable Markdown if the client sees utility, with host isolation, negative private-data tests and fresh preview read-back. Never automatically publish client data or enable tenant domains.\n\nRelease gate: PR tests + Next.js build + preview HTTP 200 for allowed host, 404 for unrelated tenant domain, correct content-type; human review of claims. Explicit operator approval for merge/production/public launch. Verify live endpoints only after approved deploy.\n\nResearch shortlist: Search Console indexing diagnostics, structured data parity, IndexNow where supported, transcript/caption accessibility, Bing Webmaster Tools, and optional schema validation. Prioritize these by observed client failures, not promises of AI ranking gains.\n
