Status: INTERNAL ONLY — no outreach authorised
Date: 2026-09-14
Basis: public website evidence only

## What we noticed

### 1. Reservation and general-enquiry paths are separate
The public site exposes a dedicated reservation route (`/contact`) and a separate general enquiry route (`/contact-us`). That can be appropriate, but the public experience does not show how those two paths are owned or followed up operationally.

### 2. Legacy route structure is still publicly discoverable
A service page remains discoverable under `/index.php/services/trois-mamelles-bassin`, while comparable current adventures use cleaner `/services/...` URLs. This is a migration/canonicalisation review item rather than evidence that the current site needs wholesale replacement.

### 3. High-value trust content should be preserved
Public pages repeatedly expose guide expertise, testimonials, tourism-authority licensing/endorsement language, conservation partnerships, and tour-specific pricing/details. Those are valuable conversion assets and should be deliberately retained through any migration.

## Why it matters
The strongest opportunity is not simply visual redesign. It is to make the path from adventure discovery to a confirmed, owned enquiry more consistent while cleaning up legacy route ambiguity without losing trust or search value.
