# WMA Preview Verification Gate

Production handoff is not permitted until this gate is satisfied or explicitly waived by Anton.

## Reachability
- [ ] Preview URL reachable
- [ ] Expected routes return intended pages
- [ ] No accidental authentication wall

## Navigation
- [ ] Primary navigation works
- [ ] Logo/home path works
- [ ] Primary CTA works
- [ ] Footer links work
- [ ] External links are intentional

## Responsive evidence
- [ ] Desktop rendered evidence captured
- [ ] Mobile rendered evidence captured
- [ ] No critical overflow/clipping
- [ ] Forms usable on mobile
- [ ] CTA remains visible/useful

## Content
- [ ] Approved copy only
- [ ] No invented claims
- [ ] Contact details correct
- [ ] Pricing correct if displayed
- [ ] Legal/policy links retained where required

## Lead path
- [ ] Form controls render
- [ ] Consent present where required
- [ ] Safe test path defined
- [ ] No unapproved live outbound message
- [ ] ERPNext/ElevenLabs changes remain unconfigured unless separately approved

## SEO / migration
- [ ] Titles/descriptions checked
- [ ] Canonical plan checked
- [ ] Old -> new URL mapping prepared where needed
- [ ] Redirect plan checked
- [ ] noindex removed only at approved launch stage

## Result
Record: PASS / PARTIAL / BLOCKED

- production deploy
- DNS/domain change
- production form routing
- production AI receptionist
