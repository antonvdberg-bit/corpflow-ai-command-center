# Change: Add internal client-intelligence context fabric

## Why
Important client research and decision rationale currently remains trapped in chat and synthetic demos. Operators need a durable, provenance-aware OrixHealth context they can interrogate during the 2 October session.

## What Changes
- Add relational internal context-space, record, source, provenance-link and relation models.
- Add an idempotent OrixHealth corpus seed mechanism from redacted durable evidence.
- Add factory-authenticated retrieval and deterministic grounded question answering.
- Add `/change/client-intelligence` as an operator call companion.

## Impact
- Affected specs: client-intelligence
- Affected code: Prisma schema/migration, factory API router, server retrieval service, operator page, seed script and focused tests.
- No production deployment, secret, external send, paid dependency or second database is introduced.
